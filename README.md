# CSU_WiFi_login_Tool
由于你←校园网每周都要重新连接，遂命令Gemini小弟制作该脚本，可以随开机自启，每隔固定时间自动检测校园网是否断连
# 中南大学 (CSU) 校园网自动登录与断网重连

单文件脚本，支持**移动 (`cmcc`) / 电信 (`telecom`) / 联通 (`unicom`) / 校园网 (`campus`)**，兼容宿舍路由器与系统代理，支持开机无黑框后台自动重连。

## 使用方法

1. **填账号**：用记事本打开 [`login.py`](login.py)，修改顶部的 3 行配置并保存：
   ```python
   USERNAME = "你的学号"
   PASSWORD = "你的密码"
   CARRIER = "cmcc"  # cmcc(移动) | telecom(电信) | unicom(联通) | campus(校园网)
   ```
2. **运行**：直接双击运行 [`login.py`](login.py)（需已安装 Python 3）：
   - 输入 **`1`**：开启 **开机自启 + 后台无黑框断网自动重连**（推荐）
   - 输入 **`2`**：仅在当前窗口运行
   - 输入 **`3`**：关闭并卸载后台自启
   - 直接 **`回车`**：仅登录一次即退出
