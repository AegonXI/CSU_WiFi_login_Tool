# 🌐 CSU-AutoLogin | 中南大学校园网自动登录与断网重连脚本

专为**中南大学 (CSU)** 校园网 (`portal.csu.edu.cn`) 打造的极简自动登录与后台断网秒级重连工具。
整个项目**只有 [`login.py`](login.py) 一个文件**，内置自动装包与交互式向导，小白也能 30 秒配好！

---

## ✨ 为什么用它？

- 📦 **单文件零门槛**：无需命令行敲 `pip install`，缺库自动补齐；双击即可弹出交互菜单一键配置。
- 📡 **宿舍路由器完美兼容**：彻底解决连接宿舍二级路由器 (`192.168.x.x`) 时报 **`联通错误代码99`** 的问题。
- 🛡️ **无视代理冲突**：底层强制直连校园网内网，电脑开着 Clash / Mihomo / VPN 也能正常重连。
- 🔄 **断网秒级无感恢复**：平时每 `10秒` 轻量巡检（CPU 占用 `0%`）；一旦中途断网或笔记本合盖唤醒，立即切换 `2秒` 高频重连。
- 👻 **开机后台无黑框**：可一键写入 Windows 系统任务计划，开机自动在后台静默守护，不弹任何烦人的黑窗口。

---

## 📖 保姆级使用说明（只需两步）

> **前提**：电脑已安装 [Python 3](https://www.python.org/downloads/)（安装时勾选 `Add Python to PATH`）。

### 第一步：填写你的学号和密码
1. 将 [`login.py`](login.py) 放到你电脑上一个固定不删的文件夹里（比如 `D:\csu_login\login.py`）。
2. 在 [`login.py`](login.py) 上**点击鼠标右键 -> 打开方式 -> 记事本**。
3. 修改最顶部的 3 行配置（保留英文双引号），然后按 `Ctrl + S` 保存关闭：

```python
# ==================== 1. 账号与运行配置 (请修改这里) ====================
USERNAME = "8212000000"         # 改成你的学号/校园网账号
PASSWORD = "YourPassword"       # 改成你的校园网密码
CARRIER = "cmcc"                # 改成你的运营商: cmcc(移动) | telecom(电信) | unicom(联通) | campus(校园网)
# ========================================================================
```

---

### 第二步：双击运行，按 `1` 开启一劳永逸模式
直接**双击运行 `login.py`**（或在终端执行 `python login.py`）：

1. 脚本会立即帮你登录校园网，并弹出菜单：
   ```text
   =======================================================
   请选择运行方式：
     [1] 开启【开机自启 + 后台无黑框自动重连】(推荐，一劳永逸)
     [2] 在当前窗口保持运行 (关掉此窗口即停止)
     [3] 关闭/卸载之前开启的后台自启
     [回车] 仅本次登录，直接退出
   =======================================================
   ```
2. 在键盘输入 **`1`** 并回车：
   - 脚本会自动将它注册到 Windows 系统的“任务计划程序”中，并在后台静默运行。
   - **从此以后，每次开机、睡眠唤醒、或者中途突然断网，电脑都会在后台自动秒级重连，你什么都不用管了！**

---

## 🛠️ 如何关闭或卸载后台自启？

如果你以后换了电脑或不想让它开机自启了，有两种方法随时关闭：

- **方法一（最简单）**：再次双击运行 [`login.py`](login.py)，在弹出的菜单中输入 **`3`** 并回车，即可一键停止后台进程并彻底卸载自启。
- **方法二（Windows 系统界面管理）**：按键盘 `Win + R` 输入 `taskschd.msc` 回车打开 **“任务计划程序”** -> 点击左侧“任务计划程序库” -> 找到名为 **`CSU_AutoLogin`** 的任务，右键即可禁用或删除。

## 💻 进阶命令行参数（可选）

如果你习惯使用终端命令，也支持直接带参数运行：

```bash
python login.py --install     # 一键注册并启动 Windows 后台静默自启
python login.py --uninstall   # 一键卸载自启并停止后台进程
python login.py --once        # 仅执行一次登录即退出
python login.py --daemon      # 直接进入持续断网重连循环
